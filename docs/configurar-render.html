Activar la demo en Render

Si «Abrir aplicación» en la landing no carga, casi siempre falta el servicio en Render (un 404 en la URL de la app).

  1. Entra en Render Dashboard.
  2. New → Blueprint y conecta el repo marlon-figueroa/app_gestor_requerimentos (usa el render.yaml del repo).
  3. Espera a que el deploy termine en verde. Copia la URL pública, por ejemplo https://gestor-requerimientos-xxxx.onrender.com.
  4. En Render, revisa que APP_URL coincida con esa URL (Render suele pedirla al crear el servicio).
  5. En GitHub: repo → Settings → Secrets and variables → Actions → Variables → crea DEMO_APP_URL con la URL de Render (sin barra final).
  6. Opcional: secret RENDER_DEPLOY_HOOK (Render → servicio → Deploy Hook) para despliegues automáticos al hacer push.
  7. Vuelve a ejecutar el workflow GitHub Pages (Actions → Run workflow) o haz un push a main.

Prueba la app directamente en la URL de Render antes de usar el botón en GitHub Pages. Debe responder en /up y redirigir a login en /.
